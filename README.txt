HOME FUSEBOX WEB APP

1. Open index.html in a browser to preview the app.
2. To publish it, upload index.html to a static website host (for example GitHub Pages or Netlify).
3. Create a QR code pointing to the published website URL and print it for the fusebox.
4. Circuit edits are saved in the browser on that device. Use Export backup before changing phones or browsers.

Important:
- This is a reference directory only. It cannot operate breakers.
- Circuit mapping and ratings must be verified by a qualified electrician.
- Do not remove the fusebox cover or touch wiring.
